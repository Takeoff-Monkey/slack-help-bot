What it does

The bot listens to Slack channels it has been invited to. When a message contains a job number in the canonical format #12345! (hash, five digits, exclamation), the bot:

  • Validates the job number against the production Google Sheet
  • Finds the matching Google Doc by searching Drive for a doc whose name contains 12345 |
  • Acknowledges the thread (":white_check_mark: Got it!")
  • Appends the full thread's messages (user, time, text) to the bottom of the doc
  • Keeps listening to subsequent replies in that thread, appending each one
  • Inserts inline images via a Google Apps Script webhook, and adds file/permalink attachments as clickable links

How to trigger / use

  • In a Slack channel where the bot is invited, start a thread with a message containing #12345! (exactly: hash, five digits, exclamation, no spaces)
  • Reply in that thread to append more notes. Each reply is logged with author + timestamp
  • Attach images directly in replies — they're pushed inline to the doc via GAS
  • Attach files (PDFs, etc.) and they're inserted as a clickable link line

Verify success

  • Bot responds with ":white_check_mark: Got it! Logging to job #12345."
  • Open the job's Google Doc — thread text appears at the bottom with author + HH:MM timestamp
  • Images appear inline in the doc; non-image files appear as ":paperclip: Attachment: [name](link)"

Common failure modes

  • ":warning: Job #12345 not found in records." — job number is not in the master Google Sheet (column A)
  • ":warning: No Google Doc found for job #12345!" — sheet has the job, but no Drive doc whose name contains 12345 |
  • ":warning: sorry, I can't process that image..." — GAS webhook failed; usually a transient GAS quota or auth issue
  • Bot silent — bot not invited to the channel, or job-number format is wrong (e.g., missing the !, extra spaces, or fewer/more than 5 digits)
  • Edits to a message don't count — the bot only sees new message events

What to collect before escalating

  • Slack channel + permalink to the thread
  • Job number used and exact message that triggered (or failed to trigger) the bot
  • Expected Google Doc name / link if known
  • Screenshot of bot's warning emoji response (if any)
  • Heroku log timestamp if you have access
