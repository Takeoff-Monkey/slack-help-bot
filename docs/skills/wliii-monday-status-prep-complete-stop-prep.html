What it does

Native Monday automation. When Status on an item is set to Prep Complete, Monday stops the active Prep time-tracking session on that item.

How to trigger / use

  • Change an item's Status column to Prep Complete.

Verify success

  • The Prep tracker is no longer running and the elapsed prep duration is recorded on the item.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
