What it does

Watches the projects inbox spam/junk folder. When a new message lands there, the Zap posts a Slack notification to the US team so we can decide whether to rescue it (it might be a legit client whose mail was misfiltered).

How to trigger / use

  • Runs automatically when an email arrives in Gmail's spam folder for projects@
  • No manual trigger

Verify success

  • A Slack message appears in the US team channel summarizing the spam-foldered email
  • Team can decide whether to whitelist / move-to-inbox

Common failure modes

  • Gmail spam-folder trigger doesn't fire (Gmail filter rules can suppress)
  • Slack channel renamed / bot removed
  • Volume spike causes Zap throttling

What to collect before escalating

  • Sender + subject + timestamp of the message that should have triggered
  • Whether the Slack channel exists and the bot is in it
  • Recent Zap run history
