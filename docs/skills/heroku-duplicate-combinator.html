What it does

Scans through specific Monday.com boards, and set groups, looking for item names that it believes to be associated with an existing item for the same project. When matches are found, items are flagged or merged according to configured rules so the queue does not contain double-entries.

How to trigger / use

  • Runs periodically against the configured Monday boards / groups — no manual trigger needed for normal operation
  • Settings can be reviewed/edited via the app link above

Verify success

  • Duplicates are flagged / merged per the configured rules
  • Fewer double-entries appear in the production queue

Common failure modes

  • Naming conventions drift, so the matcher misses real duplicates
  • False positives where similarly-named-but-distinct items get flagged
  • Monday API rate limits
  • Service down (Heroku dyno crash or deploy issue)

What to collect before escalating

  • Links to the duplicate items in question
  • Why you believe they are (or aren't) the same project
  • Timestamps of when the scan should have caught them
  • Screenshots of the items' name + key columns
