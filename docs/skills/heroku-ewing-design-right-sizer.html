What it does

Takes oversized PDF design files and compresses them to approximately 20–25 MB so they can be delivered through email and other channels with attachment size limits.

How to trigger / use

  • Invoked via Slack — submit the PDF design file to the bot and it returns a compressed version

Verify success

  • Bot returns a PDF whose file size is roughly 20–25 MB
  • The compressed PDF opens cleanly and is still legible / usable

What to collect before escalating

  • Slack channel + permalink to the message you submitted
  • Original PDF file (or link) and its size
  • Any error message returned by the bot
