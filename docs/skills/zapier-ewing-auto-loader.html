What it does

When an Ewing job arrives via email at ewing@takeoffmonkey.com, the loader parses the structured content and creates (or updates) the corresponding Monday item, sets the job number, attaches files/instruction links, and routes the item into the correct workflow.

How to trigger / use

  • Triggered automatically by inbound email to the Ewing alias
  • Ensure job number is present in the canonical format the parser expects
  • Attachments should be included in the email (or linked) so the item is created with all required artifacts

Verify success

  • A Monday item is created or updated for the job
  • Job number is set on the item
  • Instructions / files are attached in the expected columns
  • The item is in the correct group/workflow stage

Common failure modes

  • Missing or malformed job number format in the email
  • Attachment too large (>25MB) for Zapier/Gmail handoff
  • Link in the email requires auth and Zapier can't follow it
  • Monday API quota / rate limits

What to collect before escalating

  • Job number
  • Original source link / forwarded email
  • Whether files exceed ~25MB
  • Item ID if the item was partially created
