What it does

Native Monday automation. When Billing Status is set to Credit Block on a WLIII item whose Status is Delivered, a new item is created on the Credit Block / Dedicated Resource - Billing board.

How to trigger / use

  • Ensure the item's Status column is set to Delivered.
  • Change the item's Billing Status column to Credit Block.

Verify success

  • A matching item appears on Credit Block / Dedicated Resource - Billing shortly after the billing status change.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
