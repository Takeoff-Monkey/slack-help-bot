What it does

Watches for Ewing projects that come in after the 6:30pm CST cutoff. When a late submission is detected, the automation posts a Slack alert to the customer so they know the job will be queued for the next business day rather than processed that evening.

How to trigger / use

  • Runs automatically when an Ewing project is submitted past the 6:30pm CST cutoff
  • No manual trigger — the customer simply gets the alert

Verify success

  • Slack message is posted to the customer channel indicating the after-cutoff submission
  • Late-flagged Monday items are visible to the team

Common failure modes

  • Timezone misconfiguration causes false positives/negatives at the boundary
  • Slack channel renamed or bot removed
  • Monday filter misses items because of status/column rename

What to collect before escalating

  • Item link + item ID + submission timestamp (with timezone)
  • Expected vs actual Slack message (or absence thereof)
  • Slack channel name
