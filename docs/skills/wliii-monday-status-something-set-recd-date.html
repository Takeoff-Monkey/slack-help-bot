What it does

Native Monday automation (a.k.a. Auto Rec'vd Date). When the Status column changes to the trigger value configured in Monday, the item's Rec'd Date column is set to today's date.

How to trigger / use

  • Change an item's Status column to the value configured as the trigger.

Verify success

  • The item's Rec'd Date column shows today's date immediately after the status change.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
