What it does

Configured on Work Log III: when an email arrives at the connected Gmail address, a new item is created in the Inbox group on Work Log III.

Common failure modes

  • Permissions on Gmail integration (token disconnected / re-auth required).
  • Renamed Inbox group on the board.
  • Email filtered to spam or blocked before reaching the connector.

What to collect before escalating

  • Sender + subject + timestamp of the email that did not create an item.
  • Whether the email reached the inbox (vs. spam/junk).
  • Item link + item ID if an item was created partially.
