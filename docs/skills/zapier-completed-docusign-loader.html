What it does

When a DocuSign envelope is completed (all parties signed), the Zap logs a record to the Monday board so we have a single place to track signed contracts/NDAs etc., with sender, subject, and a link to the completed PDF.

How to trigger / use

  • Triggered automatically when DocuSign sends the "completed" notification
  • Routed via Gmail or DocuSign webhook depending on configuration

Verify success

  • A new item appears on the DocuSign log Monday board for the envelope
  • Item includes envelope subject, signer info, and a link to the signed PDF

Common failure modes

  • Envelope completion notification email lands in spam
  • DocuSign account auth in Zapier lapsed
  • Monday column/board renamed

What to collect before escalating

  • DocuSign envelope subject / ID
  • Timestamp of completion
  • Whether the completion email was received / where it landed
