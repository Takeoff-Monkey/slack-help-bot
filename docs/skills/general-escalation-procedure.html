What it does

Defines the standard package of context to gather any time one of our automations / apps / widgets misbehaves. Collecting these items up-front means the on-call owner (usually Tommy) can diagnose and fix the issue without going back and forth.

What to collect before escalating

  • What were you trying to do? (1 sentence)
  • Where? Board name + link + item name + item ID
  • When? Timestamp + timezone
  • What changed right before it failed? Status change, button click, file upload, etc.
  • Expected result vs. actual result
  • Screenshots: the item + the relevant columns (before / after)
  • Any error messages (Monday, Slack, email bounce, etc.)
  • Links to artifacts: Drive folder, doc links, delivered email thread if applicable

How to trigger / use

  • When you notice something broken, gather the items above before you ping anyone
  • Send the bundle to Tommy in Slack (or the specific owner if known)

Escalate to: Tommy (include all of the above so the fix is fast).
