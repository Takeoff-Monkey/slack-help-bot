What it does

Native Monday automation. When Status on an item is set to Reached out, the item is moved to the ON HOLD group.

How to trigger / use

  • Change an item's Status column to Reached out.

Verify success

  • The item appears in the ON HOLD group shortly after the status change.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
