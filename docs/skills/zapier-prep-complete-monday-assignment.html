What it does

When an item is marked prep complete, this Zap inspects the client, product type, and region on the item and sets the appropriate prepper and production team assignments so the job is routed to the right people without manual triage.

How to trigger / use

  • Triggered when the Monday status is set to Prep Complete (or equivalent)
  • Ensure client, product type, and region columns are populated before the trigger

Verify success

  • Prepper assignee is set on the item
  • Production team assignee is set on the item
  • Both assignments match the routing rules for that client/product/region

Common failure modes

  • Missing or mistyped client/product/region values
  • No routing rule configured for a new client or region
  • Status label renamed and trigger no longer matches

What to collect before escalating

  • Item link + item ID
  • Client / product type / region values on the item
  • Expected vs actual assignees
