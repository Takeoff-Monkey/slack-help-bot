What it does

Native Monday automation. When Status is set to Delivered on a WLIII item whose Billing Status is Trial, a new item is created on the New Client Trials board.

How to trigger / use

  • Ensure the item's Billing Status is Trial.
  • Change the item's Status column to Delivered.

Verify success

  • A matching item appears in New Client Trials shortly after the status change.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
