What it does

When an Ewing job is marked delivered, this Zap moves the corresponding row from the 'Active' tab on the back-up Google Sheet to the 'Delivered' tab so the active list reflects only in-flight work.

How to trigger / use

  • Triggered when an Ewing job transitions to delivered (typically a Monday status change)
  • No manual trigger needed

Verify success

  • Row removed from the 'Active' tab
  • Same row appears on the 'Delivered' tab with delivered timestamp / date

Common failure modes

  • Job row missing or has a different key (job number mismatch)
  • Sheet tab renamed
  • Google Sheets auth lapsed in Zapier

What to collect before escalating

  • Job number + Monday item link
  • Sheet link + tab names
  • Timestamp the job was marked delivered
