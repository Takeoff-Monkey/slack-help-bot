This is the living index of our tech stack: automations, apps, widgets, and workflows. Source data: Monday board 'Existing Tech' (18142222315).

How to use this doc

  • Use Ctrl/Cmd+F to find a system.
  • Each entry includes: purpose, where it runs, owner, dependencies, guide link, and how to trigger / verify it.

Index (by platform)

We keep the canonical list in Monday, but this page (and the per-skill HTML files in this folder) is optimized for humans. Entries are grouped by the platform that hosts them:

  • Heroku — Slack bots and custom Python services (Duplicate-Combinator, Ewing Revision Creator, Ewing Note Updater, Ewing Design Right-Sizer, DataChimp, Ewing Auto-Instructor, Question Relay, Estimator's Bid Notes, Catalog Matcher)
  • Zapier — Inbox loaders, folder builders, status / due-date checks, alert bots
  • AWS — Lambdas for DynamoDB imports, Worklog refresh, PDF pipelines, Gmail-to-Neon
  • Google Cloud — Streamlit widgets hub
  • Appwrite — Takeoff Monkey Widgets site (React + Appwrite functions)
  • Monday - Internal (Work Log III) — Built-in Monday automations: timestamps, group moves, time tracking, folder building
  • Chrome Extensions — Procore Worksheet Exporter

Where to start when something breaks

  • Open the skill file for the specific automation (same filename slug as its skill-id).
  • Follow its "Verify success" / "Common failure modes" checklist.
  • Gather the package described in the Escalation Procedure before pinging anyone.
