What it does

When an HLS irrigation design hits the "complete / ready for review" state on Monday, this Zap automatically assigns Muzaffar as the final reviewer so the job sits in his queue without manual handoff.

How to trigger / use

  • Triggered automatically when an HLS irrigation item reaches the review-ready status on Monday
  • No manual action needed if upstream status is set correctly

Verify success

  • Assignee/reviewer field on the HLS item is set to Muzaffar
  • Item appears in Muzaffar's filtered view / queue

Common failure modes

  • Status label rename breaks the trigger condition
  • Client/scope filter no longer matches (e.g., HLS subclient added)
  • Muzaffar's Monday user removed/changed

What to collect before escalating

  • Item link + item ID
  • Status that triggered (or should have triggered) the assignment
  • Current assignee vs expected (Muzaffar)
