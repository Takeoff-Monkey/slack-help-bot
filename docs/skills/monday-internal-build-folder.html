What it does

When 'Build Folders' is set on a Work Log III item, the folder creation process should occur (Drive / Dropbox or internal folder structure, depending on workflow). The Monday automation is the trigger; the heavy lifting is done by a downstream Zapier/Heroku worker.

How to trigger / use

  • Set the Build Folders column / button on a Work Log III item.

Verify success

  • Production folder link appears (e.g., Prod. Folder / Completed Docs link updates on the item).

Common failure modes

  • Downstream Zapier/Heroku dependency is down.
  • Missing permissions on Drive/Dropbox.
  • Naming mismatch.
  • Large file edge cases.

What to collect before escalating

  • Item ID + job number.
  • Whether Build Folders was set (screenshot of the column).
  • Any generated links (even partial).
