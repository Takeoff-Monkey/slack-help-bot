What it does

Runs in the background to pre-populate a job's instruction Google Doc with the standard requirements that apply to that job's branch, customer, region, and sales rep — so designers/preppers don't have to look them up manually each time.

What to collect before escalating

  • Job number and link to the instruction Google Doc
  • Which branch / customer / region / sales rep applied and what should have been inserted
  • Screenshot of the doc as it stands today
