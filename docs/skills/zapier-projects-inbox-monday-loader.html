What it does

A new inbound request arrives at projects@takeoffmonkey.com (or via the projects form). The Zap parses the email and automatically converts it into a Monday item on Work Log III, populating sender and any included files/links.

How to trigger / use

  • Send an email (or have a client send one) to projects@takeoffmonkey.com
  • Attachments and links should travel with the email so the resulting item is complete

Verify success

  • New item appears in the correct group/board (Work Log III) within a minute or two
  • Sender + files/links are populated on the item

Common failure modes

  • Malformed email (no subject, weird formatting from a client mail system)
  • Missing attachment or link the parser expected
  • Monday API throttling
  • Board/group mapping was changed and the Zap was not updated

What to collect before escalating

  • Original email subject + timestamp + sender
  • Expected board/group
  • Whether files were attached
  • Item ID if the item was partially created
