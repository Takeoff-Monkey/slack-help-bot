What it does

Native Monday automation. When Status changes to Complete on an item whose To Process: column is assigned to Priscilla Rosales, Monday sends Priscilla an in-app notification.

How to trigger / use

  • Ensure the item's To Process: column is assigned to Priscilla Rosales.
  • Change the item's Status column to Complete.

Verify success

  • Priscilla receives a Monday bell/notification referencing the item.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
