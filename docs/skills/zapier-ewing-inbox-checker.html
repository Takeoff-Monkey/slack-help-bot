Ewing Inbox Checker

Four separate Zapier automations (one per Ewing region) that alert the client of projects which have NOT been pushed into our queue near the region's end-of-day cutoff time.

What it does

Near each Ewing region's daily cutoff, the regional Zap scans Monday for items that arrived but have not been pushed into the active queue. If any are found, the client is alerted via Slack so they can either push the project into queue or accept that it will roll to the next day.

How to trigger / use

  • Runs on a schedule per region near the regional cutoff time
  • No manual trigger — the regional Zaps fire on their own

Verify success

  • If there are no stuck items, no message is sent (silent success)
  • If there are stuck items, a Slack alert lists them to the client

Common failure modes

  • Region-specific Zap turned off (only one of four regions affected)
  • Cutoff time / timezone misconfigured
  • Status filter no longer matches due to status rename on Monday
  • Slack channel renamed or bot removed from the channel

What to collect before escalating

  • Which region was affected
  • Expected vs actual Slack message (or absence thereof)
  • Date / timestamp the check should have run
  • Item IDs that should have been flagged
