What it does

Captures questions raised by the production team in Slack and logs them to a Google Sheet. Tracks whether the question has been manually relayed to the client, and once a response is received it automatically relays the client's answer back to the team member who originally asked.

How to trigger / use

  • Production team member asks a question via the Slack bot
  • Question is logged to the Google Sheet and a relay record is created
  • Once the client's response is captured, the bot replies to the original asker

Verify success

  • The question appears in the Question Relay Google Sheet with the asker, timestamp, and target client
  • When the client responds, the original asker receives a Slack message with the response

What to collect before escalating

  • Slack permalink to the question and the asker's user ID
  • Row in the Question Relay Google Sheet if it was created
  • Expected client + how/where the response was supplied
