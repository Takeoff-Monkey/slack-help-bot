What it does

A Slack-resident assistant backed by OpenAI and PandasAI. Users ask natural-language questions about our worklog history and the bot returns answers, tables, and charts — using the worklog data stored in DynamoDB.

How to trigger / use

  • Address questions to the DataChimp bot in Slack and it will respond with the answer / chart / table

Verify success

  • Bot responds in-channel with a coherent answer that references real worklog data
  • Tables / charts render correctly when requested

What to collect before escalating

  • Slack channel + permalink to the question that misbehaved
  • The exact prompt sent and the response received
  • Expected vs. actual answer (sample data if you can give it)
