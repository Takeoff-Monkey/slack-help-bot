What it does

Native Monday automation. When the configured button column on an item is clicked, Monday sets the item's Status column to Delivered. This typically chains into downstream automations (delivered date, group move, etc.).

How to trigger / use

  • Click the configured button on an item.

Verify success

  • The item's Status column updates to Delivered immediately after the click.

Common failure modes

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
