What it does

Native Monday automation. When Status changes to Delivered on an item where the From column equals Ratliff HS, Monday sets the item's To column to Ratliff HS.

How to trigger / use

  • Ensure the item's From column is Ratliff HS.
  • Change the item's Status column to Delivered.

Verify success

  • The item's To column shows Ratliff HS shortly after the status change.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
