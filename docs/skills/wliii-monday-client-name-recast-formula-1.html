What it does

Native Monday automation. When the Client Name column changes on an item, Monday evaluates the configured formula and writes the result into the Client Name (text, recast) column so downstream consumers can treat the value as plain text.

How to trigger / use

  • Edit or set the Client Name column on an item.

Verify success

  • The item's Client Name (text, recast) column reflects the recomputed value shortly after the change.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
