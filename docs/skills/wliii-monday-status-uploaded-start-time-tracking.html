What it does

Native Monday automation. When Status on an item is set to Uploaded, Monday automatically starts the Time Tracking timer on that item.

How to trigger / use

  • Change an item's Status column to Uploaded.

Verify success

  • The item's Time Tracking column shows an actively running timer started at (or just after) the status change.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
