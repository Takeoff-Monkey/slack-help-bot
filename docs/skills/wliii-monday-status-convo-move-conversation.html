What it does

Native Monday automation. When Status on an item is set to Convo, the item is moved to the Conversation group.

How to trigger / use

  • Change an item's Status column to Convo.

Verify success

  • The item appears in the Conversation group shortly after the status change.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
