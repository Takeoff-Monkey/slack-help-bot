What it does

Native Monday automation. When Status changes to In Process on an item whose prior Status condition is HOLD, the item is moved to the Active Projects (Uploaded / In Progress / Complete) group.

How to trigger / use

  • On an item currently with Status HOLD, change Status to In Process.

Verify success

  • The item appears in the Active Projects (Uploaded / In Progress / Complete) group shortly after the status change.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
