What it does

Native Monday automation. When a new WLIII item is created (manually, via email, via integration, or via another automation), Monday writes today's date into the Rec'd Date column.

How to trigger / use

  • Create a new item on Work Log III (any creation path).

Verify success

  • The new item's Rec'd Date column shows today's date.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
