What it does

Native Monday scheduled automation. 2 days after an item's Rec'd Date, Monday checks whether the item is still in the Cancelled Projects group and whether Status is CANCELLED. If both are true, the item is moved to the Archive of WLIII board.

How to trigger / use

  • Set an item's Status to CANCELLED and ensure it is in the Cancelled Projects group.
  • Wait until 2 days have elapsed since Rec'd Date.

Verify success

  • The item disappears from Work Log III and is present on the Archive of WLIII board.

Common failure modes

  • Permissions, renamed columns/status labels, etc.

What to collect before escalating

  • Item link + item ID + timestamp + screenshots of relevant columns.
