What it does

When an item meets the 'ready' condition (typically the assignment / send-to field, e.g. Status set to 'Uploaded'), it moves from an Inbox-style holding area into the Active group on Work Log III.

How to trigger / use

  • Set an item's Status to Uploaded (or the configured ready condition) on Work Log III.

Verify success

  • Item changes group automatically.
  • Status aligns with production flow.

Common failure modes

  • Trigger column value changed.
  • Group renamed.
  • Automation conflict with another move rule.

What to collect before escalating

  • Item link + item ID.
  • Status history (what value triggered the expected move).
  • Current group vs. expected group.
