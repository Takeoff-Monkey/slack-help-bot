What it does

Time tracking columns record work durations as users move items through the production workflow. Totals feed productivity reporting and billing analytics.

How to trigger / use

  • Time tracking starts / stops as configured against status transitions (timers fire on the workflow steps wired to the automation).

Verify success

  • Timers start/stop as expected.
  • Totals roll up to reporting.

Common failure modes

  • Users don't have permissions.
  • Column changed.
  • Automation not applied to subitems.

What to collect before escalating

  • Item link + item ID.
  • Which status change should have started / stopped tracking.
  • Screenshot of the time tracking column showing current state.
