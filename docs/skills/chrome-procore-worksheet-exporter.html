What it does

A Chrome extension that injects an "Export BOM" button into the Procore Estimating tab. Clicking the button extracts the worksheet table and downloads it as a clean CSV grouped by layer.

How to trigger / use

  • Install the extension following the Notion guide
  • Open the Procore Estimating tab for the project
  • Click the injected "Export BOM" button to download the CSV

Verify success

  • "Export BOM" button appears on the Procore Estimating tab
  • CSV downloads when the button is clicked
  • Clipboard paste works (data is structured / grouped by layer)

Common failure modes

  • Procore UI changes break the selectors the extension uses
  • Rows not loaded (need to scroll the worksheet so all rows render before exporting)
  • Extension unloaded after a Chrome update

What to collect before escalating

  • Procore URL for the worksheet
  • Screenshot of the estimating table
  • Any console errors (DevTools > Console)
  • Chrome version
