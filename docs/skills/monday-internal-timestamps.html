What it does

Status changes and/or key events on a Work Log III item update timestamp fields automatically (item creation date, plus per-stage date columns).

How to trigger / use

  • Create or update an item on Work Log III. Status changes on the configured workflow steps fire the automation.

Verify success

  • Expected date columns (e.g., Rec'd / Comp / Delivered) auto-populate when the corresponding workflow step occurs.

Common failure modes

  • Automation turned off.
  • Column renamed.
  • Status labels changed.
  • Permission changes.

What to collect before escalating

  • Item link.
  • Status history.
  • Which timestamp did not update.
