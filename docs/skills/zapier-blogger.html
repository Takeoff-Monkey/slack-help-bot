What it does

Reads a blog topic/idea (plus any seed info or notes) from a Monday item, sends it through OpenAI/Gemini for drafting, then writes the resulting article into a new Google Doc and links the doc back to the Monday item.

How to trigger / use

  • Create or update a blog topic item on the Monday board with the topic + any relevant context
  • Set the status (or button) that fires the Zap
  • The Zap drafts the article and writes the Doc

Verify success

  • A new Google Doc appears with the drafted article
  • The doc link is attached/linked back on the Monday item

Common failure modes

  • OpenAI / Gemini API rate limit or auth lapse
  • Monday trigger column/status renamed
  • Google Docs permissions for the Zapier account expired
  • Prompt produces poor / empty output if topic field is blank

What to collect before escalating

  • Monday item link + topic content
  • Whether a doc was created (link if so)
  • Recent Zap run history
