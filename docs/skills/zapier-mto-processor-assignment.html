What it does

When an MTO is created/updated in Monday, this Zap inspects the client, branch, and product type and assigns the correct processor/reviewer to the item so it routes to the right person without manual triage.

How to trigger / use

  • Runs automatically against Monday MTO items — no manual trigger required
  • Ensure client, branch, and product type fields are populated on the item

Verify success

  • Reviewer/assignee field on the Monday item is set to the expected person
  • Assignment matches the routing rules defined for that client/branch/product

Common failure modes

  • Missing or mistyped client/branch/product values
  • Routing rule not configured for a new client or product type
  • Zapier task error / API throttle

What to collect before escalating

  • Item link + item ID
  • Client, branch, and product type values on the item
  • Expected vs actual assignee
  • Timestamp
