What it does

When a job is ready for folder creation (commonly via the production workflow / "Build Folders" trigger), this automation creates and links the folder structure — day, client, and job subfolders — so the team has a place to drop drawings and deliverables. Note: although called "Dropbox" Folder Builder, we now use Google Drive for production/delivery folders, so any "Dropbox" references should be interpreted as Drive links/folders.

How to trigger / use

  • Runs automatically when a job is ready for folder creation — commonly via "Build Folders" or related production workflow step
  • No manual action required if upstream triggers fire correctly

Verify success

  • "Prod. Folder" and/or "Completed Docs" links populate on the Monday item
  • Folder exists in Dropbox/Drive with the expected day → client → job subfolder structure

Common failure modes

  • Naming mismatch between Monday fields and folder template
  • Duplicate item triggers the Zap twice
  • Dropbox/Drive permissions missing
  • Zapier task error or downstream rate limits

What to collect before escalating

  • Item link + item ID + job number
  • Timestamp
  • Screenshot of Build Folders / Billing / Links columns
  • Expected folder path
